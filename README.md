# رحلة مُنجِز — نسخة Vercel

هذه الحزمة تضم الموقع الرئيسي بكامل صفحاته، ولوحة إدارة المهام المختصرة، ومنصة مُنجِز التفصيلية.

## النشر على Vercel

1. فك ضغط الملف.
2. ارفع المجلد إلى مستودع GitHub جديد، أو افتحه في الطرفية.
3. في Vercel اختر **Add New → Project** ثم استورد المستودع.
4. اترك **Framework Preset** على **Next.js** وإعدادات البناء الافتراضية، ثم اضغط **Deploy**.
5. بعد اكتمال النشر، أضف النطاق `munjez-journey.com` من **Settings → Domains**.

لا يحتاج المشروع إلى متغيرات بيئة في نسخته الحالية. تسجيل الدخول والمهام التجريبية تُحفظ محليًا في متصفح المستخدم.

## التشغيل محليًا

```bash
npm install
npm run dev
```

ثم افتح `http://localhost:3000`.
